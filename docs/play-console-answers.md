## Foreground Service Declaration

If Play Console asks for a foreground service explanation, use this draft:

Free Noise Generator uses a foreground service for media playback. The app generates continuous brown noise and lets the user keep playback running while the app is minimized. A persistent notification shows the playback state and provides user-visible Pause, Play and Stop controls.

## Permissions

### POST_NOTIFICATIONS

Used to show the playback notification and controls on Android versions that require runtime notification permission.

### FOREGROUND_SERVICE and FOREGROUND_SERVICE_MEDIA_PLAYBACK

Used for user-visible background media playback with notification controls.

## Data Safety Short Version

Free Noise Generator does not collect or share user data. It stores only local preferences on the user's device.
